01 PHILOSOPHY & ABOUT ME

在理性的架構中，雕琢感性的互動體驗。

“

設計師的使命不僅是讓介面好看，更是成為工程實踐與人類心理之間的最佳轉譯者。以使用者為核心的研究，賦予產品堅實的靈魂；以精雕細琢的微動態，為每一次點擊帶來喜悅。

— Elena Chen, 設計宣言 (Design Manifesto)
01.1

以同理心為出發點的質化與量化研究

跳脫主觀猜測，透過深入訪談、易用性測試 (Usability Testing) 與旅程地圖，精確發掘潛在障礙，定義具商業突破點的真實痛點。

01.2

模組化設計系統與像素級的美學堅持

建立高重用性、可擴展的 Figma Design System 與 Design Tokens，兼顧視覺一致性與工程端交付 (Handoff) 效率。

01.3

跨領域對話能力與前端程式思維

熟悉 HTML5、CSS3 與前端互動邏輯，能以工程師同理的語言探討動效邊界與技術可行性，讓卓越設計精準落實。

02 CAPABILITIES & TOOLKIT

跨越研究、視覺與程式的全向度技能矩陣

以全流程產品思維為骨架，融合前瞻美感與工程可行性，構築完整的設計落地能力。

CAT. 01 PRODUCT & USER EXPERIENCE

UI/UX 產品體驗與使用者研究

  • 用戶訪談與易用性測試 (Usability Testing) 熟練

    主持超過 25+ 場受訪者深度測試，制定量化 SUS 與質化親和圖

  • Figma 元件庫與設計系統架構 (Design Systems) 精通

    熟稔 Auto Layout, Variables, Component Properties 與 Token 規範

  • 線框圖與高保真原型 (Wireframing & Prototyping) 精通

    從低保真 User Flow 迅速迭代至高保真可互動展示原型

  • 資訊架構 (IA) 與用戶旅程圖 (Journey Mapping) 熟練

    梳理複雜產品功能層級，確保導航邏輯直觀清晰

CAT. 02 VISUAL & INTERACTION CRAFT

視覺排版、品牌識別與動態設計

  • 字體排印學與雜誌級版面編排 (Typography & Grid) 精通

    嚴謹的基線網格 (Baseline Grid)、層級對比與節奏呼吸感

  • 微互動與動態轉場 (Motion Design / After Effects) 熟練

    精準控制貝茲曲線與動態時長 (Easing & Timing)，產出 Lottie 檔

  • 3D 元素探索與數位場景 (Blender / Spline 3D) 進階

    材質打光、基礎幾何建模，無縫嵌入現代 Web 介面

  • 色彩體系規劃與無障礙設計 (Color & WCAG 2.1) 熟練

    深淺色自適應色盤配置，對比度全面達標 AAA/AA 規範

CAT. 03 DESIGN-TO-CODE ALIGNMENT

前端開發共感與數位實現

  • 現代響應式排版 (Modern Semantic HTML5 & CSS3) 精通

    CSS Grid, Flexbox, 自定義變數系統與流暢動效處理

  • 基礎 JavaScript / DOM 互動邏輯 熟練

    獨立撰寫頁面微互動、滾動事件、主題切換與表單邏輯

  • Git 版本控制與團隊協作流程 熟練

    理解分支管理、Pull Request 與開發者 Handoff 規範

  • AI 輔助設計探索 (Midjourney, Prompt Engineering) 精通

    高效生成 Moodboard、概念視覺與高擬真原型素材
